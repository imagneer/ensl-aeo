## 2026-09-04 — 예산 소진 사고 ($0.04 초과로 API 차단)

**발단**: Anthropic 크레딧 잔액이 -$0.04가 되면서 API 호출이 차단됨.

**원인 (코드로 확인 완료)**:
1. 2026-09-03에 배포한 "경쟁사 특징 추출 2단계" 확장으로 daily 집계당
   LLM 호출이 최대 4배(타겟 1 + 경쟁사 최대 3) 늘어남 — 조합당 최대
   72×4=288회(이전 최대 72회).
2. 2026-09-03 11:24~11:50 KST에 기존 504개 daily 행에 대한 일회성
   백필(`backfillCompetitorKeywords`)을 5회 호출 — 내부적으로 604~738회
   실제 LLM 호출 발생.
3. 그날 밤(UTC 9/3 15:30 = KST 9/4 00:30) 경쟁사 확장이 포함된 첫
   `aggregate-daily` 자동 실행이 겹침 — 같은 UTC 날짜 버킷에 두 이벤트가
   같이 잡힘.
4. `lib/keyword-extractor.ts`가 `data.usage`를 로그로 안 남기고 있어서,
   사고 이후 정확한 토큰/비용을 사후 복원할 수 없었음.

**9/3 UTC 스파이크($3.03) 분해 (추정, 실측 아님)**:
- 평상시 하루 기본선 ≈ $0.6
- 백필 604~738회 × 건당 ≈ $0.002~0.003 ≈ **$1.5~2.2** (일회성)
- 첫 확장 크론 추가분 ≤216회 ≈ **$0.4~0.65** (매일 반복되는 고정비 증가)
- 합계 ≈ $2.5~3.4 → 실측 $3.03과 정합

**결론**: 백필이 그날 스파이크의 주범, 경쟁사 확장 크론은 앞으로의
고정비 증가(하루 최대 $0.4~0.65 수준 추정).

**조치 (작업지시서_LLM비용_안전장치_2026-09-04.md 기준, 코난 구현)**:
- `lib/llm-usage.ts` 신설 — ANTHROPIC_API_URL을 fetch하는 7곳(전부) 호출
  usage를 구조화 로그로 기록(성공/실패 둘 다). `aggregate-daily` 실행
  1회당 `llmCalls`/`llmCallsByKind`/토큰 합계를 응답·로그에 노출.
- `backfillCompetitorKeywords()`에 `?dryRun=1` 추정 모드 추가(실제 호출
  없이 예상 건수·토큰·비용만 계산).
- `MAX_LLM_CALLS_PER_RUN=400`(`lib/llm-config.ts`) 상한 추가 — 크론
  1회 실행이 이 상한을 넘으면 남은 조합을 중단하고 로그를 남김.
- 경쟁사 키워드 추출 기능 자체는 롤백하지 않음(Day21 브랜드 현 위치
  화면이 이 데이터를 쓰고 있어 루아 결정 대기 — 작업지시서 "하지 말 것" 1번).
