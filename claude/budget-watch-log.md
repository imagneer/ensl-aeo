# 엔슬 AEO MVP — 플랫폼별 예산 점검 로그

매주 월요일 자동 점검(scheduled task) + 예산 관련 사고 발생 시 수시 기록. 새 회차는 표 맨 아래에 행/섹션만 추가할 것 — 기존 행 삭제/수정 금지.

> **파일 관리 참고 (2026-09-14 재병합)**: 이 파일은 claude.ai 프로젝트 문서(에일이 관리, 매주 예산 점검 루틴이 씀)와 로컬 git 레포 `claude/budget-watch-log.md`(코난이 작업 중 직접 씀) 두 곳에 따로 존재해서 두 번째로 갈라졌던 걸 오늘 다시 병합함. **첫 번째 갈라짐은 2026-09-04에 있었음**(코난이 "기존 파일 없음"으로 판단해 새로 만드는 사고) — 그때도 병합해서 바로잡았었는데, 이후 각자 계속 수정하면서 다시 벌어짐. **앞으로 규칙: 이 파일의 정본은 로컬 레포(git 커밋 대상)이고, 에일이 매주 점검 후 이 파일에 직접 반영한 뒤 프로젝트 문서에도 동일 내용을 동기화한다.** 코난이 이 파일에 직접 쓸 때는(사고 대응 등) 다음 정기 동기화 때 프로젝트 쪽에도 반영됨.

## 배경
2026-08 말, OpenAI 비용이 PRD 예산($6/월 추정, gpt-5.6-luna 가정)보다 훨씬 많이 나가고 있는 걸 뒤늦게 발견함. 실제로는 `gpt-5-search-api`(검색 그라운딩을 항상 강제하는 검색 전용 모델) 사용 중이라 토큰비 + 웹서치 툴 콜 비용이 별도로 붙는 구조. 이건 버그가 아니라 측정 정확성을 위한 의도된 설계였지만, PRD 비용표가 이 변경을 반영하지 못해 예산과 실측치가 어긋났던 것. 이 계기로 매주 정기 점검 루틴을 만듦.
