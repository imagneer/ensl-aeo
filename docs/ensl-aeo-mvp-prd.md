# Ensl AEO Monitoring MVP — PRD v0.2

**작성일:** 2026-08-06
**작성자:** 루아 (박희은)
**상태:** 초안 — Day 3 대화형 정의 기반


## 1. 제품 개요

### 이 MVP는 뭔가?
AI 답변 엔진(구글AI, ChatGPT, Gemini, Claude, Perplexity)에서 특정 브랜드가 어떻게 언급되고 있는지를 자동으로 추적하고, 동시에 GA4 유입 데이터를 연동해 AI 노출 변화가 실제 트래픽에 어떤 영향을 주는지까지 한 화면에서 볼 수 있는 모니터링 대시보드. 대부분의 GEO 도구가 "AI에 나왔는지"만 보여주는 데 반해, 이 MVP는 "나온 결과가 실제 유입으로 이어지는지"까지 연결한다.

### 왜 만드는가?
원탑치과 재직 당시, 5개 AI 엔진에 매일 직접 질문을 던지고 순위·키워드·경쟁사를 수동으로 구글 시트에 기록했다. 약 4개월간(2026.02~06) 운영한 이 수동 프로세스는 작동했지만, 다수 클라이언트를 동시에 서비스하려면 자동화가 필수다.

### 누가 쓰는가?
- **1차 사용자:** 루아 (엔슬 운영자) — 데이터 수집·분석·진단
- **2차 사용자:** 엔슬 클라이언트 — 대시보드 열람 (URL 공유 방식)

### MVP에서 하지 않는 것
- 로그인/인증 시스템
- 클라이언트별 계정 분리
- 네이버 SEO 노출 자동 추적 (공식 API 없음, 스크래핑 리스크)
- 덴트웹 등 외부 CRM 연동
- 비용/ROI 계산


## 2. 핵심 기능

### 기능 A: AI 엔진 브랜드 모니터링 (핵심)

5개 AI 엔진에 사전 정의된 쿼리를 자동으로 보내고, 응답에서 다음을 추출한다:

| 측정 항목 | 설명 | 원탑 시트 대응 |
|---|---|---|
| 노출 여부 | 브랜드명이 답변에 등장하는지 | 구글AI(1위) / 미노출 |
| 순위 | 답변 내 몇 번째로 언급되는지 | 1위, 2위, 3위... |
| 노출 키워드 | AI가 브랜드를 설명할 때 사용한 표현 | "서울대, 협진, 365, 디지털" |
| 경쟁사 동시 노출 | 같은 답변에 함께 언급된 브랜드 + 순위 | (원탑 시트에는 비체계적으로 존재) |
| 인용 출처 | AI가 참고한 소스 URL (제공 시) | (일부 엔진만 제공) |

**측정 대상 엔진:**
1. 구글 AI (AI Overviews / Gemini 통합 검색)
2. ChatGPT (OpenAI)
3. Gemini (Google, 독립형)
4. Claude (Anthropic)
5. Perplexity

**측정 조건:**
- 쿼리는 브랜드별로 사전 정의 (예: "강서구에서 임플란트 잘하는 치과 알려줘")
- 비로그인/시크릿/임시채팅 조건을 최대한 재현
- 1회 측정은 일화(anecdote)이지 데이터가 아님 — 동일 쿼리 복수 회 실행 후 노출률로 표기

**핵심 설계 원칙: AEO는 확률싸움이다**

원탑치과 55영업일 수동 측정에서 검증된 세 가지 원칙:

1. **확률변수로 저장한다.** 노출 여부를 boolean(나왔다/안 나왔다)이 아니라 노출률(%)로, 순위를 단일 숫자가 아니라 분포(평균 순위 + 표준편차)로 저장한다. "오늘 1위"가 아니라 "오늘 5회 중 3회 1위, 노출률 60%"가 의미 있는 데이터다.

2. **공간(시점 내 반복) × 시간(시계열) 둘 다 확보한다.** 수동 측정은 하루 1회밖에 못 해서 시간축만 확보했다. 자동화의 유일한 실질 우위는 "같은 시점에서 여러 번 반복"을 추가할 수 있다는 것. 이걸 안 살리면 자동화의 의미가 없다.

3. **단발 관측으로 결론 내지 않는다 — 가드레일로 하드코딩한다.** 1회 관측에서 미노출이 나와도 알림을 보내지 않는다. 최소 3시점 이상 반복 확인 + 경쟁사 동조 여부 확인을 거쳐야만 "신호"로 판정한다.

**측정 볼륨 (단계적 확장):**

| 단계 | 쿼리 수 | 엔진 | 시점 내 반복 | 시간대 | 일일 호출 수 |
|---|---|---|---|---|---|
| MVP 1단계 | 3~5개 | 5개 | 3회 | 하루 2회 | ~150회 |
| MVP 2단계 | 10~20개 | 5개 | 5회 | 하루 3회 | ~1,500회 |
| 목표 (표준) | 50개+ | 5개 | 5회 | 하루 3회 | ~3,750회 |

MVP 1단계는 Vercel Pro($20/월)로 커버 가능. 확률 측정 구조는 처음부터 심되, 볼륨은 검증 후 확장.

**알림(Alert) 가드레일:**
- 알림 발생 조건 (두 조건 모두 충족 필수):
  - (a) 동일 신호가 최소 3시점 이상 반복 관측됨
  - (b) 경쟁사 동조 여부 확인 완료 — "우리만 빠졌다" vs "시장 전체가 흔들린다" 구분
- 단발 outlier는 저장은 하되 알림은 보내지 않음
- 대시보드 UI에 "이 관측은 X시점 반복 확인됨" 뱃지 표시

### 기능 B: GA4 유입 데이터 연동

Google Analytics Data API를 통해 일일 채널별 세션 수를 자동 수집:

| 채널 | 설명 |
|---|---|
| 네이버 (검색) | utm_source=naver |
| 네이버 플레이스 | utm_source=naver, utm_medium=map |
| 구글 | google / organic |
| ChatGPT | chatgpt.com referral |
| BING | bing |
| 소셜 채널들 | 인스타, 유튜브, 당근, 카카오, 스레드 등 |
| 총유입 | 전체 세션 수 |

**참고:** 전환 데이터(예약, 상담폼)도 GA4 API로 가져올 수 있으나, 클라이언트별 전환 이벤트 설정이 다르므로 MVP 이후 단계에서 유연하게 대응.


## 3. 대시보드 화면 구성 (초안)

### 화면 1: AI 노출 요약 (메인)
- 브랜드 선택 드롭다운
- 엔진별 최신 노출 상태 카드 (순위 + 노출 키워드)
- 시계열 차트: 엔진별 순위 변화 추이
- 노출 키워드 변화 타임라인 (어떤 표현이 언제 등장/소멸했는지)

### 화면 2: 경쟁사 비교
- 같은 쿼리에서 동시 노출된 브랜드별 순위 비교
- Share of Voice: 전체 측정 중 각 브랜드가 등장한 비율

### 화면 3: 유입 현황 (GA4)
- 채널별 일일 세션 수 시계열
- AI 채널(ChatGPT 등) 유입 추이 별도 하이라이트
- 기간 비교 (전주 대비, 전월 대비)

## 5. 아키텍처 개요

```
[Vercel Cron] ──── 트리거 (하루 2시간대)
       │
       ▼
[수집 오케스트레이터] ──── 쿼리 × 엔진 × 반복(3~5회) 배치 실행
       │
       ├── [OpenAI 어댑터] ──── ChatGPT API
       ├── [Anthropic 어댑터] ── Claude API
       ├── [Google 어댑터] ──── Gemini API
       ├── [Perplexity 어댑터] ─ Perplexity API
       └── [Google AI 어댑터] ── (구글 AI Overviews — 별도 조사 필요)
       │
       ▼
[파싱 엔진]
  - 브랜드 멘션 감지
  - 순위 추출
  - 키워드 추출
  - 경쟁사 감지
  - 출처 URL 추출
       │
       ▼
[Supabase PostgreSQL]
  - snapshots (원시 데이터 — 매 호출 저장)
  - aggregated_metrics (집계 — 노출률%, 평균 순위, 표준편차)
       │
       ▼
[판정 로직] ──── 가드레일: 3시점 반복 + 경쟁사 동조 확인
       │
       ▼
[Next.js 대시보드] ──── shadcn/ui + Recharts
  - "X시점 반복 확인됨" 뱃지
  - 노출률(%) 기반 시계열
```


## 6. 데이터 구조 (개념 수준)

MVP Day 4에서 상세 스키마를 설계할 예정. 여기서는 핵심 엔티티만 정의:

- **brands** — 모니터링 대상 브랜드 (이름, 카테고리, 관련 쿼리 목록)
- **queries** — 측정용 쿼리 텍스트 + 대상 브랜드 연결
- **snapshots** — 개별 API 호출 단위의 원시 데이터 (타임스탬프, 엔진, 쿼리, 전체 응답 텍스트). 반복 측정의 각 회차가 각각 1행.
- **mentions** — snapshot에서 파싱된 개별 결과 (브랜드, 순위, 노출 키워드, 경쟁사, 출처)
- **aggregated_metrics** — 동일 (쿼리, 엔진, 시간대)의 반복 측정을 집계한 확률 데이터: 노출률(%), 평균 순위, 순위 표준편차, 관측 횟수. 대시보드는 이 테이블을 기준으로 표시.
- **ga4_sessions** — GA4에서 가져온 채널별 일일 세션 수


## 7. 알려진 제약과 리스크

### 측정 정확성
- ChatGPT는 모델 라우팅·검색 호출 여부·샘플링이 매번 달라서 같은 질문도 결과가 바뀜. 복수 회 측정 후 노출률(%)로 표기해야 의미 있음.
- ChatGPT 시크릿모드 폐지 — 로그인+임시채팅이 현실적 최선이나 API 호출과 웹 UI 결과가 다를 수 있음.
- Gemini 시크릿 vs ChatGPT 임시채팅은 조건 비대칭 — 완전히 동일한 조건 재현은 불가, 한계로 명시하고 진행.

### 기술적 리스크
- **구글 AI Overviews**: 공식 API 없음. 웹 스크래핑 또는 Gemini API로 대체 가능성 조사 필요.
- **API 비용**: MVP 1단계 기준 일 ~150회 호출. Week 2 어댑터 개발 시 엔진별 단가 기반 월 비용 추정 필수.
- **Vercel Cron 제한**: Hobby 플랜(하루 2회, 10초)으로는 반복 측정 불가 → Pro 플랜($20/월, 60초) 필요. 150회 호출을 2시간대로 나눠 배치 실행하는 구조 설계 필요.

### 범위 리스크
- GA4 연동은 "nice to have"로 우선순위 낮출 수 있음. AI 모니터링이 반드시 먼저.

- GA4 전환 이벤트 커스텀 연동

- 경쟁사 자동 발견 (수동 등록 → AI 답변에서 자동 감지)
- 알림 시스템 확장 (이메일/슬랙 연동 등 채널 다양화)
